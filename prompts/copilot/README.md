# Prompts Copilot — Index

Ce dossier contient les prompts réutilisables pour déclencher les workflows d'orchestration depuis GitHub Copilot.

## Utilisation

Copier le contenu d'un prompt et l'envoyer dans le chat Copilot, ou référencer le fichier directement via `#file:`.

## Prompts disponibles

| Fichier | Mode | Usage |
|---|---|---|
| `discover.prompt.md` | DISCOVER | Cadrer un nouveau projet |
| `bootstrap.prompt.md` | BOOTSTRAP | Initialiser un projet après validation |
| `resume.prompt.md` | RESUME | Reprendre un projet existant |
| `status.prompt.md` | STATUS | Restituer l'état d'un projet |
| `replan.prompt.md` | REPLAN | Proposer une évolution du plan |
| `close.prompt.md` | CLOSE | Vérifier et clôturer un projet |

## Documentation complète

Voir `docs/copilot/orchestration.md` pour la description détaillée de chaque mode.

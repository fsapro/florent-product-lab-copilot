# Product Agent Template

Template minimal pour un projet produit avec spec-kit.

Moteur d'execution : spec-kit. Voir `.github/copilot-instructions.md`.

## Contenu

- `.github/copilot-instructions.md` — regles permanentes de gouvernance
- `.github/PULL_REQUEST_TEMPLATE.md` — formulaire PR avec verification independante
- `docs/product/plan.md` — plan PM (a adapter au projet)
- `docs/decisions/` — ADR (Principe VI : une ADR par decision structurante)
- `docs/learnings/` — apprentissages locaux
- `docs/independent-verification.md` — verification par session distincte

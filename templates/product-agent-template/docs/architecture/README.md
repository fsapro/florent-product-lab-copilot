# Architecture vivante

Ce dossier décrit uniquement l'architecture utile au produit et à sa maintenance.

La source d'autorité du design courant est `docs/solution-design/solution-design.md`.
Les décisions structurantes sont tracées dans `docs/decisions/`.

## Contenu attendu

- vues métier, données, applications, composants, technologie et exploitation lorsque concernées ;
- schémas ou tableaux légers si utiles ;
- liens vers ADR et PRs ;
- écarts connus entre architecture actuelle et cible.

Ne pas documenter une architecture exhaustive si le changement est local et réversible.
